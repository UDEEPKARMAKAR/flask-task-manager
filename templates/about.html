About This App

This is a simple Task Manager built with Python Flask as a mini project. You can add tasks with a priority, mark them as done, delete them, and filter the list.

Features

  • Add a task using a form (POST)
  • View and filter tasks (GET)
  • Mark tasks as completed or delete them (POST)
  • Input validation with friendly error messages
